# GeoCameraPro example

This app demonstrates the package camera preview, front/rear switching,
foreground-started background GPS tracking, portrait photo capture, and saved
image/GPS metadata.

Run on an Android or iOS device:

```shell
flutter pub get
flutter run
```

See the package [README](../README.md) for platform permissions, background
tracking restrictions, configuration, and troubleshooting. Test camera and
background tracking on physical devices; emulator behavior does not represent
all OS or manufacturer power policies.
